## POST /api/conversation

Stream a conversation turn

Operation ID: `converse_api_conversation_post`. Authentication: required when access gate is enabled.

Stream UTF-8 newline-delimited JSON, one complete object per line.

Append text chunks, update tool status by ID, render outfit cards and offer
action routes without automatically launching cameras or paid generation.
Only `done` confirms success: save its conversation_id for the next turn.
An `error` is terminal even when HTTP status is 200; EOF without either is
an interrupted turn. Error codes are stable machine-readable categories;
`retryable` permits an explicit retry, not automatic replay of actions.
Sessions are ephemeral server memory; omitting the ID starts a new session.

Request: `application/json` (required).

```json
{
  "$ref": "#/components/schemas/ConversationRequest"
}
```

Responses:

- `200`: UTF-8 NDJSON stream. Each line is one event from this union, not a JSON array. Ends with done or error; HTTP 200 alone does not mean the turn succeeded. (`application/x-ndjson`)
- `422`: Validation Error (`application/json`)
- `401`: Deployment access code is required or invalid. (`application/json`)
- `429`: Rate limit, concurrent generation cap, or live quota exceeded. Honor Retry-After. (`application/json`)
- `413`: Request exceeds deployment body cap (16 MiB by default). (`application/json`)
